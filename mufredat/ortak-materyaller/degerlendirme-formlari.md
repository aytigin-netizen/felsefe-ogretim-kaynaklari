# Öz ve Akran Değerlendirme Formları (Ortak Materyal)

Bu dosya, tüm 10. sınıf ünitelerinde resmî programın öngördüğü öz değerlendirme ve akran değerlendirme süreçleri için ortak şablonlar içerir. 10. sınıf programının ilgili ünitelerinde (1., 3., 8. ve 9. üniteler) bu iki formun kullanılması açıkça öngörülmüştür.

---

## Form 1: Öz Değerlendirme Formu

Öğrenci, ünite sürecinde kendi öğrenmesini ve katılımını değerlendirir. Her ifade için 1 (Hiç) — 2 (Bazen) — 3 (Çoğu zaman) — 4 (Her zaman) ölçeği kullanılır.

| # | İfade | 1 | 2 | 3 | 4 |
|---|-------|---|---|---|---|
| 1 | Ünite kavramlarını (kavram kartındaki anahtar kavramlar) kendi cümlelerimle açıklayabiliyorum | | | | |
| 2 | Öğrenme çıktılarında geçen becerileri (açıklama, sorgulama, muhakeme) yerine getirebiliyorum | | | | |
| 3 | Tartışmalara etkin dinleme yaparak ve söz kesmeden katıldım | | | | |
| 4 | Görüşlerimi gerekçeli biçimde ifade edebildim | | | | |
| 5 | Farklı görüşlere karşı açık fikirli ve saygılı davrandım | | | | |
| 6 | Görev ve sorumluluklarımı zamanında ve etik ilkelere uygun tamamladım | | | | |
| 7 | Kavram yanılgılarımı veya öğrenme eksiklerimi fark ettim | | | | |

**Refleksiyon soruları:**

1. Bu ünitede en çok ne öğrendim?
2. Hâlâ anlamakta zorlandığım bir kavram veya problem var mı? Varsa ne?
3. Bir sonraki derste kendimi nasıl geliştirmeliyim?

## Form 2: Akran Değerlendirme Formu

Öğrenci, grup çalışmasındaki veya sunumdaki bir arkadaşının performansını değerlendirir. Her ifade için 1 (Hiç) — 2 (Bazen) — 3 (Çoğu zaman) — 4 (Her zaman) ölçeği kullanılır. Değerlendirme **saygı ve nezaket** çerçevesinde yapılır; amaç yargılamak değil geliştirmektir.

| # | İfade | 1 | 2 | 3 | 4 |
|---|-------|---|---|---|---|
| 1 | Görevini zamanında ve eksiksiz yerine getirdi | | | | |
| 2 | Grup tartışmasına fikirleriyle katkıda bulundu | | | | |
| 3 | Görüşlerini gerekçelendirdi (kanıt veya örnek verdi) | | | | |
| 4 | Başkalarının sözünü dinledi, sözünü kesmedi | | | | |
| 5 | Farklı görüşlere karşı hoşgörülü ve yapıcı davrandı | | | | |
| 6 | Ürüne (tablo, harita, sunum, yazı) somut katkı sağladı | | | | |

**Akran notu:** Arkadaşının en güçlü yanını ve geliştirilmesi gereken bir yanını birer cümleyle yaz.

| Güçlü yan | Geliştirilecek yan |

| | |

---

## Kullanım Kılavuzu

Öz değerlendirme formu ünitenin son dersinde bireysel doldurulur; akran değerlendirme formu ise grup çalışması, tartışma çemberi, kart düellosu veya sunum gibi iş birlikli etkinliklerin sonunda kullanılır. Her iki form da değerlendirme sürecinde dönüt aracı olarak kullanılmalı, öğrenciye puan yerine gelişim önerisi sağlanmalıdır. Formlar, ünitelerin "Değerlendirme" bölümlerinde geçen öz/akran değerlendirme gerekliliklerini karşılar.
