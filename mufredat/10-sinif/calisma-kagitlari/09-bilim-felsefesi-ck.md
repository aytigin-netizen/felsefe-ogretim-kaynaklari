# Çalışma Materyali — 9. Ünite: Bilim Felsefesi

Bu dosya, MEB onaylı programın 9. ünite "Öğrenme Kanıtları" bölümünde öngörülen **eşleştirme testi**, **boşluk doldurma**, **kavram haritası** ve **bulmaca** gerekliliklerini somutlaştırır. Ünite kazanımı FEL.10.9.1 ile uyumludur.

## Materyal 1: Eşleştirme Testi

Bilim felsefesi kavramlarını tanımlarıyla eşleştirin.

| Kavram | Cevap | Tanım |
|--------|-------|-------|
| ____ Gözlem | | A. Deneyle çürütülebilir olma; Popper'a göre bilimselliğin ölçütü |
| ____ Hipotez | | B. Bir bilim topluluğunun paylaştığı kuram, yöntem ve örnek kümesi |
| ____ Kuram | | C. Duyulara ve ölçüm araçlarına dayalı veri toplama |
| ____ Yasa | | D. Gözlem → hipotez → deney → kuram aşamalarını izleyen sistemli süreç |
| ____ Doğrulama | | E. Deneylerle tekrar tekrar onanmış, genel ilişki ifadesi |
| ____ Yanlışlama | | F. Bilimsel görünüm taşıyan ama bilimsel yöntemi kullanmayan iddia sistemi |
| ____ Paradigma | | G. Kapsamlı, deneylerle sınanmış açıklama sistemi |
| ____ Bilimsel yöntem | | H. Bir önermenin gözlem/deneyle desteklendiğini gösterme çabası |
| ____ Sözde bilim | | I. Sınanmaya aday, geçici açıklama önermesi |

### Cevap Anahtarı (Öğretmen İçin)

Gözlem-C, Hipotez-I, Kuram-G, Yasa-E, Doğrulama-H, Yanlışlama-A, Paradigma-B, Bilimsel yöntem-D, Sözde bilim-F

## Materyal 2: Boşluk Doldurma Çalışma Kâğıdı

1. Bilim felsefesi; bilimin ne olduğunu, nasıl ilerlediğini ve bilimsel bilginin __________ felsefi yöntemle inceleyen daldır.
2. Mantıksal pozitivizmin önde gelen temsilcisi __________, anlamlı önermenin deneyle doğrulanabilir olması gerektiğini savunmuştur.
3. K. Popper'a göre bilimi bilim yapan şey doğrulanabilirlik değil, __________ olmalıdır.
4. T. S. Kuhn, bilimin __________ değişimleriyle kesintili olarak ilerlediğini öne sürmüştür.
5. İbni Heysem'in __________ deneyi, deneysel yöntemin erken örneklerinden biridir.
6. Michelson-Morley deneyi, ışık hızının __________ olduğunu ortaya koyarak fizik kuramlarının dönüşümüne katkı sağlamıştır.
7. Milgram'ın __________ deneyi, sosyal bilimlerde deneysel yöntem ve etik tartışmalarının önemli örneklerindendir.
8. Klasik bilim anlayışı bilgiyi __________ ve kümülatif görürken, çağdaş anlayış bilginin her an düzeltilebilir olduğunu vurgular.
9. Hayatta En Hakiki Mürşit İlimdir sözüyle bilinen Türk düşünür __________, bilim felsefesi performans görevinde incelenen eserlerinden birine de adını vermiştir.
10. Sosyal bilimlerde yöntem tartışmaları bağlamında __________ yöntem araştırılabilir.

### Cevap Anahtarı (Öğretmen İçin)

1. değerini 2. R. Carnap 3. yanlışlanabilirlik 4. paradigma 5. Karanlık Oda 6. sabit 7. Otorite ve İtaat 8. kesin 9. A. Sayılı 10. hermeneutik
