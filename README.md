# Felsefe Öğretim Kaynakları

Türkiye Maarif Modeli Felsefe Öğretim Programı (2026) için açık kaynak 
kaynakları ve pratik ders materyalleri.

## İçerik

- **Müfredat**: 10. ve 11. sınıf felsefe programı (yapılandırılmış)
- **Ders Planları**: Hazır ders planı şablonları
- **Etkinlikler**: Tartışma soruları, araştırma görevleri
- **Sunumlar**: pptxgenjs ile üretilmiş dinamik sunumlar
- **Değerlendirme**: Rubrikler, kontrol listeleri
